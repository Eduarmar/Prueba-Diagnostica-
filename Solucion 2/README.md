# Proyecto: Generador y Evaluador de Polinomios

## Descripción
Este programa calcula los coeficientes de un polinomio de la forma (x+1)^n utilizando el triángulo de Pascal, y evalúa paso a paso el polinomio para un valor de x dado.

## Estructura
- `polinomios.py`: Contiene el código fuente del programa.
- `dependencies.sh`: Script para verificar que Python está instalado. No se requieren dependencias adicionales.
- `README.md`: Documentación del proyecto.

## Requisitos
- **Python** 3.6 o superior.

## Cómo ejecutar
1. Descarga la carpeta `Solucion 2`.
2. Abre un terminal y navega a la carpeta con:
   ```bash
   cd ruta/a/Solucion 2
3. Ejecuta el programa con: 
        python polinomios.py
4. Ingresa el grado del polinomio (n) y el valor de (x) cuando el programa lo solicite. 
        
        Por ejemplo:
        Ingrese el grado del polinomio (n): 3
        Ingrese el valor de x: 2

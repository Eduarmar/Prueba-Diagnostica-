# Proyecto: Contador y Resaltador de Palabras en una Cadena

## Descripción
Este programa, cuenta cuántas veces aparece una palabra en una cadena y resalta todas las ocurrencias encontradas.

## Estructura
- `cadena_ocurrencias.py`: Contiene el código fuente del programa.
- `dependencies.sh`: Script para verificar que Python está instalado. No se requieren dependencias adicionales.
- `README.md`: Documentación del proyecto.

## Requisitos
- **Python** 3.6 o superior.

## Cómo ejecutar
1. Descarga la carpeta `Solucion_4`.
2. Abre un terminal y navega a la carpeta con:
   ```bash
   cd ruta/a/Solucion_4
3. Ejecuta el programa con: 
        python cadena_ocurrencias.py
4. Ingresa la cadena y la palabra que deseas buscar cuando el programa lo solicite:
        
        Por ejemplo: 
                Entrada: 
                        Ingrese la cadena: Este es un ejemplo de ejemplo con otro ejemplo.
                        Ingrese la palabra a buscar: ejemplo
                Salida:
                        La palabra 'ejemplo' aparece 3 veces en la cadena.

                        Cadena con la palabra resaltada:
                        Este es un **ejemplo** de **ejemplo** con otro **ejemplo**.

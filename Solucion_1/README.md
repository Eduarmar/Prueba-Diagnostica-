# Proyecto: Validador de Notacion FEN

## Descripcion
Este programa valida si una cadena ingresada cumple con el formato FEN (Forsyth-Edwards Notation), utilizado en ajedrez para representar posiciones en el tablero.

## Estructura
- `notacion_fen.py`: Contiene el codigo fuente del programa.
- `Dependencias.sh`: Script para verificar que Python esté instalado. No se requieren dependencias adicionales.
- `README.md`: Este archivo de documentacion.

## Requisitos
- **Python** 3.6 o superior.

## Pasos para ejecutar
1. Descarga la carpeta `Solucion_1`.
2. Abre un terminal y navega a la carpeta con:
   ```bash
   cd ruta/a/Solucion_1
3. Ejecuta el programa con: 
        python fen_notation.py
4. Ingresa una cadena en notación FEN cuando el programa lo solicite. 
        
        Por ejemplo:
         Ingrese la cadena para validar: rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1
